# 시대생존록

**UOS: University of Survivors**

서울시립대학교 캠퍼스를 배경으로 PC 브라우저에서 4~8명이 참여하는 실시간 2D 탑다운 좀비 게임입니다.

**Phase 5 — 캐릭터 시스템 기반**을 진행 중입니다. 방장이 4~8명의 시작 인원을 확정하면 서버가 시작 좀비 한 명과 특수 좀비 캐릭터를 무작위 배정합니다. 나머지는 인원별 고정 비율에 따라 시대생(HUMAN_000)과 중복 없는 특수 인간(화석·스과생·조각학도·공대생·컴과생·철학도)으로 배정합니다. 고유 능력과 소환 엔티티는 서버 권위형이며, 인간은 감염되면 기존 연결을 유지한 채 일반 좀비로 전환됩니다.

| 시작 인원 | 특수 좀비 | 시대생 | 특수 인간 |
|---:|---:|---:|---:|
| 4 | 1 | 1 | 2 |
| 5 | 1 | 2 | 2 |
| 6 | 1 | 2 | 3 |
| 7 | 1 | 2 | 4 |
| 8 | 1 | 3 | 4 |

시대생은 고유 능력 없이 이동·Space 상호작용·공통 위험 감지를 사용합니다. 시작 후 합류자는 시대생으로 참여하며 기존 배정을 다시 계산하지 않습니다. 게임 시작 소개 화면에는 본인의 정보만 표시하고 캐릭터 선택·재추첨은 제공하지 않습니다.

## 요구 환경

기본 맵은 32px 타일의 전체 캠퍼스 야외 초안(3120×1680)입니다. 7분 경기에서 5분 45초에 경고하고, 6분에 네 출구 중 서버가 선택한 두 곳을 공개합니다. 인간이 열린 출구에서 Space를 1초 유지하면 탈출하며 한 명 이상 탈출 시 인간 승리를 확보합니다. 남은 참가자의 결과를 기록한 뒤 7분에 종료하거나 활동 중인 인간이 없으면 조기 종료합니다.

맵 선택과 같은 맵끼리의 빠른 참여를 지원합니다. 새 맵의 좌표·충돌·출구·스폰·은신처를 공유 데이터에 등록하면 렌더링과 서버 판정에 함께 적용됩니다. [맵 추가 방법과 경기 규칙](./docs/MAPS.md)을 참고하세요.

캠퍼스 외형은 학교 사진을 참고한 부드러운 탑다운 일러스트입니다. 건물마다 벽돌·밝은 외벽·유리·세로 마감과 지붕 특징을 구분하며, 맵에는 픽셀 확대와 반복 잔디 격자를 사용하지 않습니다. [건물별 참고 자료](./docs/CAMPUS_ART.md)를 기록했으며 개발 서버의 `/map-preview.html`에서 구역별로 확인할 수 있습니다.

- Node.js 22 이상
- pnpm 11 이상

## 시작하기

```bash
pnpm install
pnpm dev
```

- 웹 클라이언트: <http://localhost:5173>
- 게임 서버: <http://localhost:2567>
- 서버 상태 확인: <http://localhost:2567/health>

1. 닉네임을 입력합니다.
2. 빠른 참여로 입장 가능한 공개방을 찾거나 새 공개방을 자동 생성합니다.
3. 직접 방을 만들 때 공개방 또는 초대 코드 전용 비공개방을 선택할 수 있습니다.
4. 참가자가 4~8명 모이면 방장이 시작 버튼을 누릅니다. 본인의 캐릭터 소개를 확인한 뒤 방향키로 이동합니다. `Shift`는 고유 능력, `Space`는 인간의 지형·시설 상호작용 또는 모든 좀비의 근접 기본공격입니다. 시대생과 일반 좀비는 Shift 능력이 없습니다. 화석은 은신처 근처에서 `Space`로 숨거나 나옵니다.

서로 다른 브라우저 창에서 같은 초대 코드로 접속하면 실시간 동기화를 확인할 수 있습니다.

서버는 이동 입력을 허용 범위로 보정하며 좌표를 클라이언트에서 직접 받지 않습니다. 게임 중 페이지를 새로고침하면 저장된 재접속 토큰으로 같은 플레이어 세션을 복원합니다.

좀비 기본공격의 거리·방향·2초 쿨타임·감염 판정은 서버가 결정합니다. 기본공격에는 준비시간과 공격 후 경직이 없습니다.

화석의 은신 가능 여부, 은신처 1회 소모, 최대 20초 타이머와 퇴장 위치도 서버가 결정합니다. 은신 중에는 이동·공격이 차단되고 다른 플레이어에게 해당 캐릭터의 상태와 위치가 전송되지 않습니다. 맵별 야외 후보에서 서버가 경기마다 5곳을 선택하며 사용 가능 표시는 화석에게만 작은 효과로 보입니다.

스과생은 6초 동안 기본 이동 속도의 140%로 달린 뒤 2초 동안 65% 속도로 탈진합니다. 스킬 발동 순간부터 25초 쿨타임이 적용되며, 감염되면 모든 인간 스킬 상태가 즉시 제거됩니다.

조각학도는 `Shift`로 현재 위치에 조각상을 생성합니다. 조각상은 서버가 기록한 직전 5초의 이동 방향을 인간 속도의 85%로 한 번 재생하고 사라집니다. 좀비가 조각상을 공격하면 조각상은 파괴되고 해당 좀비만 1.5초간 이동·공격이 잠깁니다. 재사용 대기시간은 30초입니다.

인간 공통 패시브 위험 감지는 4타일 이내 좀비를 자동 감지해 화면 가장자리에 대칭 붉은 효과를 표시합니다. 2~4타일은 약한 경고, 2타일 미만은 강한 맥동이며 위치·방향·종류를 알려주지 않습니다. 위장 엑스맨은 최대 약한 경고까지만 발생하고 은신 화석에게는 표시하지 않습니다. 여러 좀비가 있으면 각 대상의 단계 중 가장 높은 단계를 사용합니다.

최초 좀비는 만취생·대학원생·중도 NPC·지각생·엑스맨·교수님 중 무작위 배정하며 감염된 인간은 일반 좀비가 됩니다. 대학원생은 `Shift`로 가장 가까운 인간 한 명을 4초간 추적합니다(재사용 35초). 화면 안에는 노란 외곽 강조, 밖에는 작은 원형 방향 화살표가 표시됩니다. 은신한 화석과 조각상은 탐지하지 않으며 추적 정보는 본인에게만 전달됩니다. 모든 좀비의 `Space` 기본공격은 즉시 1회 판정하고 2초 쿨타임을 적용합니다.

엑스맨은 `Shift` 새터 잠입으로 최대 10초 동안 인간 외형으로 위장합니다(재사용 40초). 실제 진영은 좀비이며 이동속도는 위장 중 100%, 해제 후 108%입니다. 가능한 `Space` 공격은 위장을 즉시 해제하고 같은 입력으로 판정하며, `Shift` 재입력 또는 시간 만료로 해제하면 0.5초 동안 공격이 제한됩니다. 화면에는 인간처럼 표시하지만 네트워크 수준에서 실제 진영 데이터를 은폐하는 기능은 포함하지 않습니다.

지각생은 `Shift` 출석 마감으로 고정된 방향으로 최대 3타일을 0.5초간 돌진합니다(재사용 25초). 첫 인간에 닿으면 즉시 일반 좀비로 감염시키고 종료하며, 벽에 닿아도 추가 경직 없이 멈춥니다. 조각상은 파괴하면서 지각생에게 1.5초 기절을 적용하고, 은신 화석과 책더미는 통과합니다. 평상시 이동속도는 인간 기본속도의 108%입니다.

중도 NPC는 `Shift`로 전방 2타일에 2×1타일 책더미를 설치합니다(유지 12초, 재사용 30초, 최대 1개). 인간과 조각상은 막고 좀비는 통과합니다. 벽·플레이어·책더미와 겹치거나 보호 지점의 마지막 경로를 차단하면 설치를 거부하며 쿨타임을 소모하지 않습니다. 맵별 스폰과 출구는 보호 경로 지점으로 관리합니다.
