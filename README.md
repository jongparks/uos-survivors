# 시대생존록

**UOS: University of Survivors**

서울시립대학교 캠퍼스를 배경으로 PC 브라우저에서 4~8명이 참여하는 실시간 2D 탑다운 좀비 게임입니다.

**Phase 5 — 캐릭터 시스템 기반**을 진행 중입니다. 인간은 경기 시작 시 `화석(HUMAN_001)`, `스과생(HUMAN_002)`, `조각학도(HUMAN_003)` 중 하나로 서버에서 무작위 배정됩니다. 모든 고유 능력과 조각상 같은 소환 엔티티는 서버 권위형으로 동작합니다. 최소 2명이 모이면 첫 참가자가 최초 좀비가 되며, 좀비 공격이 인간에게 한 번 명중하면 즉시 감염됩니다.

## 요구 환경

- Node.js 22 이상
- pnpm 11 이상

## 시작하기

```bash
pnpm install
pnpm dev
```

- 웹 클라이언트: <http://localhost:5173>
- 게임 서버: <http://localhost:2567>
- 서버 상태 확인: <http://localhost:2567/health>

1. 닉네임을 입력합니다.
2. 빠른 참여로 입장 가능한 공개방을 찾거나 새 공개방을 자동 생성합니다.
3. 직접 방을 만들 때 공개방 또는 초대 코드 전용 비공개방을 선택할 수 있습니다.
4. 게임 화면에서 방향키로 이동합니다. `Shift`는 고유 능력, `Space`는 인간의 지형·시설 상호작용 또는 모든 좀비의 근접 기본공격에 사용합니다. 일반 좀비는 Shift 고유 능력이 없습니다. 화석은 등록된 은신처 근처에서 `Space`로 숨거나 나옵니다.

서로 다른 브라우저 창에서 같은 초대 코드로 접속하면 실시간 동기화를 확인할 수 있습니다.

서버는 이동 입력을 허용 범위로 보정하며 좌표를 클라이언트에서 직접 받지 않습니다. 게임 중 페이지를 새로고침하면 저장된 재접속 토큰으로 같은 플레이어 세션을 복원합니다.

좀비 공격의 거리, 방향, 0.7초 쿨타임, 감염과 승리 판정은 모두 서버가 결정합니다.

화석의 은신 가능 여부, 은신처 1회 소모, 최대 20초 타이머와 퇴장 위치도 서버가 결정합니다. 은신 중에는 이동·공격이 차단되고 다른 플레이어에게 해당 캐릭터의 상태와 위치가 전송되지 않습니다. 현재 테스트 맵에는 실제 지형지물이 없어 은신처 후보를 비워 두었으며, 맵 제작 후 [`hideSpotRegistry.ts`](./apps/server/src/maps/hideSpotRegistry.ts)에 후보를 등록하면 활성화됩니다.

스과생은 6초 동안 기본 이동 속도의 140%로 달린 뒤 2초 동안 65% 속도로 탈진합니다. 스킬 발동 순간부터 25초 쿨타임이 적용되며, 감염되면 모든 인간 스킬 상태가 즉시 제거됩니다.

조각학도는 `Shift`로 현재 위치에 조각상을 생성합니다. 조각상은 서버가 기록한 직전 5초의 이동 방향을 인간 속도의 85%로 한 번 재생하고 사라집니다. 좀비가 조각상을 공격하면 조각상은 파괴되고 해당 좀비만 1.5초간 이동·공격이 잠깁니다. 재사용 대기시간은 30초입니다.
