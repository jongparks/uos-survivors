# 조각학도 (HUMAN_003)

- 영문명: Sculpture Student
- 진영: 인간
- 역할: 교란
- 고유 능력: 살아있는 조각상 (`SCULPTURE_DECOY`)

조각학도는 공용 능력 키 `Shift`로 자신의 현재 위치에 조각상을 생성합니다. 서버는 매 시뮬레이션 틱의 검증된 이동 방향과 정지 입력을 최근 5초까지만 기록하며, 조각상은 이 기록을 생성 위치 기준으로 한 번 재생합니다. 실제 좌표나 생성 이후 플레이어 움직임은 복제하지 않습니다.

- 유지시간과 이동 기록: 5초
- 이동 속도: 기본 인간 속도의 85%
- 동시 활성화: 플레이어당 1개
- 내구도: 좀비 공격 1회
- 공격한 좀비 기절: 1.5초
- 재사용 대기시간: 30초

조각상도 플레이어와 같은 서버 충돌 계산을 사용하므로 벽과 맵 바깥을 통과하지 않습니다. 모든 플레이어에게 서버 좌표가 동기화되지만 실제 플레이어 수, 감염, 시설·아이템 상호작용, 목표 진행에는 포함되지 않습니다.

좀비 공격 범위 안에 인간과 조각상이 함께 있으면 더 가까운 대상을 공격합니다. 조각상을 맞힌 좀비만 1.5초 동안 이동·공격·능력이 차단되며, 자연 소멸에는 기절이 발생하지 않습니다. 조각학도가 감염되거나 방을 떠나면 활성 조각상은 즉시 제거됩니다.
