# 지각생 — ZOMBIE_004

- 최초 특수 좀비 배정 목록에 포함. 감염 결과는 기존 일반 좀비 유지.
- Shift 출석 마감: 발동 순간 방향 정규화 및 고정, 500ms에 최대 3타일(초당 288px), 발동 시 25초 쿨타임.
- 평상시 인간 기본속도의 108%. 기존 다른 특수 좀비 속도는 변경하지 않는다.
- 서버가 이동 입력 대신 돌진 경로를 계산한다. 벽·장애물·실제 인간·조각상에 연속 충돌 검사를 적용하고 가장 먼저 충돌한 대상만 처리한다.
- 같은 거리에서는 벽 → 조각상 → 인간, 같은 종류에서는 세션 ID 순서로 판정한다.
- 인간 충돌은 공통 감염 시스템으로 일반 좀비 전환, 돌진 종료. 최대 1명 감염.
- 은신 화석 및 좀비는 감염 대상에서 제외. 책더미는 좀비 통과 규칙 유지.
- 조각상 충돌은 기존 피격 처리로 조각상 파괴 및 지각생 1.5초 기절.
- 시간·거리 종료, 벽 충돌, 외부 기절, 연결 해제, 경기 종료 시 돌진 종료. 벽 충돌 후 추가 기절·탈진 없음.
- 시작/종료/방향 상태를 공유하고 클라이언트는 고정 방향 이동 예측과 짧은 잔상을 표시한다.
- Space 공통 기본공격은 기존 즉시 1회, 준비/후경직 없음, 2초 쿨타임 유지.
