# 컴과생 — HUMAN_005

- 인간 무작위 배정 5종에 포함. 별도 원화 없이 기존 인간 외형 사용, 위험 감지 공통 패시브 적용.
- Shift Ctrl + Z: 준비/이동 잠금 없이 정확히 3초 전 위치로 즉시 복귀. 성공 시 40초 쿨타임.
- 서버는 50ms 간격 위치를 최근 3.5초 순환 버퍼에 저장한다. 서버 틱 사이의 표본과 정확한 복귀 시점은 선형 보간한다.
- 현재 벽·책더미·다른 플레이어 몸체와 충돌하면 자신의 기록 경로를 현재 방향으로 탐색한다. 약 1px 간격으로 검사해 첫 유효 지점을 선택한다. 없으면 실패하고 쿨타임 미소모.
- 이전 순간이동 전후는 같은 타임스탬프의 두 표본으로 남겨 순간이동 사이의 허공을 이동 경로로 취급하지 않는다.
- 감염·기절·강제 행동·3초 미만 기록·쿨타임 중 사용 거부. 위치만 복귀하고 진영/상태/다른 쿨타임/방향은 복구하지 않는다.
- 공대생 함정은 인간 복귀를 막지 않는다. 웅덩이 둔화는 복귀 위치의 현재 범위 규칙으로 계산한다.
- 서버의 기존 입력 처리 순서에 따라 감염이 먼저 확정되면 거부한다. 기록은 이탈·경기 초기화에서 정리한다.
- 복귀 성공 시 위험 감지의 100ms 간격을 무효화해 같은 틱에 새 위치의 단계를 재계산한다.
- 복귀 전 위치에 짧은 파란 잔상, 복귀 위치에 파란 픽셀 효과 표시. 순간이동 직후 300ms는 보간값 대신 서버 좌표를 표시하여 짧은 복귀도 미끄러지지 않도록 한다.
