# 대학원생 — ZOMBIE_002

특수 좀비. 최초 좀비 및 최초 좀비 이탈 시 대체 캐릭터 목록에 만취생과 함께 포함한다. 인간 감염 결과는 계속 일반 좀비이다.

- Shift: 교수님이 찾으신다. 서버가 맵 전체에서 직선거리 기준 가장 가까운 활동 중 인간 한 명을 선정한다. 동거리에서는 세션 ID 순으로 결정한다.
- 4초 동안 대상 고정 및 실시간 위치 갱신. 발동 시 35초 쿨타임 시작.
- 탐지 가능한 인간이 없으면 발동·쿨타임 모두 없음.
- 은신 화석·조각상·좀비·연결 해제 인간은 후보에서 제외한다.
- 대상 감염·은신·퇴장·연결 해제 시 추적 종료. 다른 대상으로 전환하지 않고 쿨타임은 유지한다.
- 추적 ID·좌표·타이머는 서버 전용 런타임에 저장하고 `graduate:tracking` 개인 메시지로 소유자에게만 보낸다. 공유 상태에 포함하지 않는다.
- 재접속하면 서버에 남은 유효한 추적과 쿨타임을 다음 갱신에서 복원한다.
- 화면 안에서는 노란색 외곽 강조. 화면 밖에서는 지름 24px 원형 화살표를 가장자리에서 20px 안쪽에 표시한다. 거리·닉네임 표시는 없다.
- Space 공통 기본공격: 준비/후경직 없음, 즉시 1회 판정, 쿨타임 2초.
