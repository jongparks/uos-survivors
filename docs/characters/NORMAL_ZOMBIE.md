# 일반 좀비 — ZOMBIE_000

외형은 사용자 제공 `apps/web/src/assets/characters/normal_zombie.svg` 및 동봉 JSON을 사용한다. 발 기준점 (0.5, 0.92), 기본 오른쪽 방향/왼쪽 이동 시 반전, 선형 필터링을 적용한다. 게임 표시 크기는 44px 너비에 원본 비율을 유지한다. 현재 제공본은 정지 자세이며 걷기·공격 프레임은 추후 별도 자산으로 교체한다. JSON의 미정 능력치와 제안 충돌 범위는 게임 규칙을 변경하지 않는다.

- 인간 감염 시 기존 세션을 유지하고 일반 좀비로 전환한다. 중복 감염은 거부한다.
- 최초 좀비 및 최초 좀비 이탈 시 대체 선정은 특수 좀비 목록에서만 선택한다.
- 인간 기본 속도의 108%. 서버 이동과 클라이언트 예측에 같은 배율을 사용한다.
- 감염 시 은신·질주·탈진·인간 쿨타임·조각상·기절 상태를 정리한다.
- Shift 고유 능력 없음. 만취생의 숙취 폭발을 사용할 수 없다.
- 사용자 결정: 모든 좀비의 Space는 공통 근접 기본공격이다. 인간의 Space는 상호작용이다.
- 공격 범위·공격 간격·감염 직후 공격 잠금은 기존 COMBAT_RULES를 사용한다.
- 모든 좀비의 기본공격: 준비시간 0초, 공격 후 경직 0초, 즉시 1회 판정, 쿨타임 2초. 빗맞혀도 쿨타임이 적용되며 HUD에 남은 시간을 표시한다. 쿨타임 중 이동과 고유 능력은 별도로 사용할 수 있다.
- 기본공격 감염 필요 횟수는 최종 미정이며 현재는 기존 1회 감염 동작을 유지한다.
- 특수 좀비는 Shift 고유 능력과 Space 기본공격을 함께 사용할 수 있다.
