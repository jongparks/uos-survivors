# 공대생 — HUMAN_004 (최종 설계 v1.1)

- 인간 무작위 배정 4종에 포함. 기존 제외된 전전컴 대신 새 공대생 최종 설계 적용.
- Shift 밤샘 제작: 현재 위치에서 500ms 제작 중 이동 불가, 설치 완료 500ms 후 활성화.
- 설치 성공부터 30초 쿨타임, 설치 완료부터 20초 수명, 최대 활성 함정 1개. 제작 중 감염·기절·이탈 시 취소하고 쿨타임 미소모.
- 함정의 바닥 표시 및 충돌 크기는 인간 기본 몸체 26px 기준. 인간은 통과하고 활성 함정에 닿은 좀비 한 명을 2.5초 ROOT 후 소모한다.
- ROOT는 이동만 차단한다. 방향 전환·Space 기본공격·비이동 스킬은 허용하며, 지각생 돌진은 거부한다. 중첩·지속시간 갱신 없음.
- 지각생은 실제 돌진 상태에서 면역. 통과한 함정은 유지하고, 서버가 마지막 돌진 이동을 처리한 직후 종료 위치에서만 함정을 재검사한다.
- 위장 엑스맨은 ROOT와 동시에 위장 해제, 500ms 공격 잠금. 기존 40초 위장 쿨타임 유지. 위험 감지는 같은 틱에 재계산한다.
- 인간은 모든 함정을 수신하고 카메라 안에서 표시. 좀비는 1.5타일 이내 함정만 StateView로 수신한다. 위장 엑스맨도 실제 좀비 기준으로 가시성을 제한한다.
- 감염·이탈 시 소유 함정 제거, 경기 종료/초기화 시 함정과 ROOT 정리. 재접속 시 현재 진영·거리로 가시성 복원.
- 별도 캐릭터 원화는 아직 없으며 기존 인간 표시와 제작/함정/ROOT 표시를 사용한다. 위험 감지 공통 패시브 적용.
