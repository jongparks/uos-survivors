# 만취생 — ZOMBIE_001

명세 v1.1 기반. 최초 좀비와 감염된 인간에게 현재 유일한 좀비 캐릭터인 만취생을 배정한다.

- Shift: 숙취 폭발. 기존 Shift 근접공격 대신 사용한다.
- 준비 500ms, 방향 고정, 발동 시 30초 재사용 대기시간 시작.
- 준비 중 이동 가능. 기절 시 발사 취소, 재사용 대기시간 유지.
- 투사체 1개, 초당 8타일, 사거리 5타일, 충돌 반경은 인간 반경의 25%.
- 서버의 연속 경로 충돌 검사로 가장 먼저 닿은 대상만 처리한다.
- 같은 거리에서는 벽 → 조각상 → 인간 순서, 같은 종류는 ID 순서로 결정한다.
- 인간 직접 적중은 기존 감염 처리를 사용하며 웅덩이를 만들지 않는다.
- 조각상 직접 적중은 파괴 및 발사자 1.5초 기절, 웅덩이 없음.
- 벽·장애물 또는 사거리 종료는 마지막 유효 위치에 웅덩이를 생성한다.
- 웅덩이는 반경 1타일, 지속 4초. 인간의 유효 이동속도에 0.75를 곱한다.
- 겹쳐도 동일 둔화는 중첩하지 않으며, 좀비에게는 적용하지 않는다. 웅덩이는 감염시키지 않는다.
- 웅덩이와 발사된 투사체는 소유자와 독립적으로 유지되며 방 초기화 시 정리된다.
- 준비 동작, 투사체, 웅덩이는 공유 상태를 통해 모든 클라이언트에 표시한다.

검증: 준비/취소/방향/중복 요청, 첫 대상 감염, 벽 차단, 조각상 충돌, 사거리·웅덩이 수명·비중첩 둔화 단위 검사 및 실제 서버 연결 감염 검사.
