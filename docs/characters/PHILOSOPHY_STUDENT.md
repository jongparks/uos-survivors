# 철학도 — HUMAN_006

사용자 수정에 따라 표시 이름은 철학도. HUMAN_006과 능력 규칙은 원래 설계대로 유지한다.

- Shift 소크라테스의 문답법: 직선거리 3타일 이내 가장 가까운 활동 중 좀비 한 명에게 3초 CONFUSION. 시야/벽 검사 없음, 같은 거리에서는 세션 ID 순서로 결정.
- 성공 시 40초 쿨타임. 대상 없음·감염·기절·쿨타임·가장 가까운 대상이 이미 혼란 상태이면 실패 및 쿨타임 미소모. 두 번째 대상으로 건너뛰지 않음.
- 이동 입력의 두 축만 반전. 서버와 클라이언트 예측은 같은 변환 함수를 사용하며 대각선 정규화/충돌은 기존 이동 시스템 유지.
- 공격·Space·고유 능력·각 쿨타임은 변경하지 않음. 진행 중 지각생 돌진 방향을 뒤집지 않고 종료 후 남은 시간에만 일반 이동을 반전.
- 엑스맨은 위장 중에도 대상이지만 위장과 기존 쿨타임은 유지. 물음표 표시로 수상한 상태가 드러날 수 있음.
- ROOT와 혼란 타이머는 독립적이며 혼란은 중첩/갱신하지 않음.
- 대상 본인에게 철학적 혼란 제목·설명·남은 시간·카운트다운 바·반전 방향 안내. 모두에게 머리 위 작은 물음표 표시. 상태는 서버 타임스탬프로 동기화하며 추가 발동 메시지로 중복 효과를 만들지 않음.
- 인간 무작위 배정 6종에 포함, 위험 감지 공통 패시브 적용. 별도 원화는 아직 없어 기본 인간 표시를 사용.
- 감염 및 경기 초기화 시 인간 스킬 쿨타임 정리. 경기 종료 시 혼란 표시 제거.
