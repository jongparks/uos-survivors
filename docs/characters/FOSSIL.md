# 화석 (HUMAN_001)

- 영문명: Fossil
- 진영: 인간
- 역할: 은신
- 고유 능력: 비밀 은신처 (`FOSSIL_HIDE`)

화석은 맵이 제공하는 은신처 중 경기마다 서버가 선정한 5곳을 확인할 수 있습니다. 각 은신처는 한 번만 사용할 수 있고, 진입 후 최대 20초 동안 이동·능력·상호작용이 차단됩니다. 은신처 근처에서 `Space`로 숨고 다시 `Space`를 누르면 일찍 나올 수 있으며, 시간이 끝나면 서버가 자동으로 등록된 출구 좌표에 배치합니다.

은신 중 캐릭터는 서버의 권위 상태와 타이머에는 유지되지만 다른 클라이언트의 상태 뷰에서는 제거됩니다. 따라서 다른 플레이어에게 위치 갱신, 은신 상태, 전용 알림이 전송되지 않습니다. 화석 본인에게만 사용 가능한 은신처의 작은 링 이펙트와 상호작용 문구가 표시됩니다.

## 맵 연결 방법

실제 맵이 완성되면 `apps/server/src/maps/hideSpotRegistry.ts`의 `CURRENT_MAP_HIDE_SPOT_CANDIDATES`에 다음 정보를 등록합니다.

- `id`: 맵 내 고유 ID
- `zoneId`: 은신처 분산 선정을 위한 구역 ID
- `x`, `y`: 상호작용 중심 좌표
- `exitX`, `exitY`: 충돌하지 않는 퇴장 좌표
- `interactionRadius`: 해당 지형에 맞춘 상호작용 반경

후보가 비어 있으면 능력만 비활성화되어 현재 테스트 맵 진행을 막지 않습니다. 후보를 일부만 등록한 상태에서 5개보다 적으면 서버가 맵 설정 오류로 경기 시작을 차단합니다.
