# 교수님 — ZOMBIE_006

- 최초 특수 좀비 풀에 포함. 인간 배정 비율/특수 인간 중복 금지 및 감염 시 일반 좀비 전환은 유지.
- Shift 과제 제출하세요: 4타일 이내 가장 가까운 유효 인간 한 명에게 최대 3초 ASSIGNMENT_LOCK. 은신 화석·조각상·이미 구속 중인 인간 제외, 벽/시야 검사 없음.
- 서버가 2~4개 방향키를 무작위 생성하며 반복 키 허용. 정답은 진행, 오답은 0으로 초기화. 모두 맞히거나 3초 경과 시 즉시 해제.
- 대상에게만 `assignment:state`로 정답·진행·기한을 전송한다. 입력은 `assignment:direction_input`의 미션 ID/방향을 실제 연결 세션에 대해 검증한다. 다른 대상/지난 미션/임의 완료 요청은 무시한다.
- 대상은 이동·Shift·Space 금지, 방향키 keydown만 미션으로 소비하며 키를 길게 누른 반복 이벤트는 전송하지 않는다.
- 미션 UI는 본인 캐릭터 상단에 제목·방향키·진행도·남은 시간. 정답 초록색, 오답 짧은 붉은 점멸, 성공 시 짧은 초록 효과 후 제거. 다른 플레이어에게는 구속 테두리만 표시한다.
- 성공 시 교수님 스킬 쿨타임 40초 및 기본공격 잠금 1초. 기존 2초 공격 쿨타임은 유지하며 이동/방향 전환 및 다른 좀비의 공격에는 영향 없음.
- 스과생 질주/탈진 타이머, 설치된 함정/조각상, 기존 혼란 효과, 인간 위험 감지는 그대로 동작한다. 공대생의 진행 중 제작은 구속 시 취소하며 미설치 쿨타임은 부여하지 않는다.
- 감염·대상 또는 시전자 연결 종료·경기 종료 시 미션 취소. 재접속은 취소 상태를 동기화하며 지난 미션을 복원하지 않는다.
- 사용자 제공 `professor.svg`/JSON을 적용한다. 원본 비율·발 기준점 (0.5, 0.92)·좌우 반전·선형 필터링과 기존 이동/공격 동작을 사용한다. 이름은 확정 명세의 교수님, 능력은 과제 제출하세요를 유지한다.
- 동봉 JSON의 F 학점/이동 둔화/다른 좀비 우선 추적/추천 스폰은 제안 자료이며 이번 외형 적용으로 게임 규칙을 변경하지 않는다. 레이저 선과 점은 원본 그림의 일부이고 실제 표적 지정 효과가 아니다.
