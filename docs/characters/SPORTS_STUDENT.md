# 스과생 (HUMAN_002)

- 영문명: Sports Science Student
- 진영: 인간
- 역할: 기동
- 고유 능력: 전력 질주 (`SPORTS_SPRINT`)

스과생은 공용 능력 키인 `Shift`로 전력 질주를 요청합니다. 서버가 캐릭터·진영·현재 상태·쿨타임을 검증한 뒤 다음 상태를 순서대로 적용합니다.

- 0~6초: 기본 이동 속도의 140%
- 6~8초: 탈진, 기본 이동 속도의 65%
- 8~25초: 기본 이동 속도, 쿨타임 유지
- 25초 이후: 다시 사용 가능

가속과 탈진 중에도 방향 변경과 기존 벽 충돌 판정은 유지됩니다. 스킬을 중간에 취소하거나 중복 입력으로 지속 시간을 초기화할 수 없습니다. 감염되면 가속·탈진·쿨타임이 모두 즉시 제거되고 좀비 이동 규칙만 적용됩니다.

캐릭터는 로비에서 선택하지 않으며, 경기 시작 시 서버가 현재 인간 캐릭터 목록에서 무작위 배정합니다.
