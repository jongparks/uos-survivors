# 중도 NPC — ZOMBIE_003

- 최초 특수 좀비 무작위 배정 목록에 포함. 감염된 인간은 계속 일반 좀비가 된다.
- Shift: 자리 맡아놨습니다. 서버가 현재 바라보는 방향으로 정확히 2타일 앞에 가로 2×1타일 책더미를 설치한다. 대각선 방향도 정규화하며 장애물을 회전시키지 않는다.
- 12초 유지, 성공 시 30초 쿨타임, 소유자당 활성 책더미 1개. 실패 시 소모 없음 및 개인 실패 안내.
- 벽·맵 밖·모든 플레이어·기존 책더미와 겹치면 거부한다.
- 인간과 조각상은 통과 불가. 일반·특수 좀비는 통과 가능. 피해·파괴·투사체 차단 효과 없음.
- 서버 이동과 클라이언트 예측은 동일한 몸체 크기 및 책더미 충돌 함수를 사용한다. 이동을 작은 구간으로 나누어 빠른 이동의 관통을 막는다.
- 책더미가 생성되면 작은 등장 효과를 표시하며 공유 상태로 위치와 소멸을 동기화한다. 경기 종료/초기화 시 정리한다.
- 경로 검사는 기존 활성 책더미를 포함하고, 설치 전 연결되어 있던 보호 지점 및 인간 위치의 연결을 설치 후에도 유지한다. 반 타일 격자에서 인간 크기와 중간 경로 충돌을 검사한다.
- 현재 테스트 맵은 주요 스폰 지점으로 각 구역의 연결을 보호한다. 향후 탈출 시설·필수 상호작용 접근점·출입구는 `apps/server/src/maps/protectedNavigationPoints.ts`에 등록한다. 아직 없는 승리 목표는 추가하지 않는다.
- Space 공통 기본공격은 준비/후경직 없이 즉시 1회 판정, 2초 쿨타임을 유지한다.
