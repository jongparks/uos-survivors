# 좀비 외형 및 간단 동작

사용자 제공 `uos_zombies.zip`의 만취생·대학원생·중도 NPC SVG와 JSON을 `apps/web/src/assets/characters/`에 보관한다. 일반 좀비는 앞서 적용한 동일 그림을 유지한다. PNG 여러 해상도 대신 벡터 원본을 불러와 텍스처로 사용한다.

- `zombieDesigns.ts`가 캐릭터 ID와 외형을 연결한다. 원본 비율, 발 기준점 (0.5, 0.92), 선형 필터링 및 좌우 반전을 적용한다.
- 공통 동작은 이동 거리 기반 작은 들썩임/기울임, 정지 시 부드러운 복원, 서버 승인 기본공격에 맞춘 240ms 몸 내밀기와 복원이다.
- 움직이는 장식은 실제 게임 좌표와 분리하며 충돌 영역과 공격 범위는 변경하지 않는다.
- 위장 상태의 엑스맨은 외형 등록보다 인간 표시를 우선한다. 신규 디자인이 없는 캐릭터는 기존 임시 표시를 사용한다.
- 동봉 JSON은 디자인 참고 자료이며 능력 변경 지시가 아니다. 만취생의 병/가스 설명, 대학원생의 다른 좀비에게 공유한다는 설명 등 기존 확정 명세와 다른 내용은 게임에 적용하지 않는다.
- 대학원생 SVG의 청록색 선/조준점, 중도 NPC의 바닥 책 등은 원본 그림의 일부다. 실제 추적 대상 표시 및 설치된 충돌 책더미와는 별도다.

추가 걷기/공격 프레임은 생성하지 않고 기존 원화에 간단한 변형만 적용한다. 향후 별도 프레임이 제공되면 외형 등록부와 공통 표시 계층을 확장할 수 있다.
