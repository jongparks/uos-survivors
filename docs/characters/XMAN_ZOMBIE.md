# 엑스맨 — ZOMBIE_005

- 최초 특수 좀비 무작위 배정 목록에 포함. 감염된 인간은 기존 일반 좀비 전환 유지.
- Shift 새터 잠입: 10초 동안 인간 외형, 발동 시 40초 쿨타임 시작.
- 실제 진영/캐릭터는 좀비/엑스맨 유지. 인간 전용 능력·시설 권한을 얻지 않는다.
- 위장 중 이동속도 100%, 해제 시 108%. 서버 이동과 클라이언트 예측에 같은 배율을 사용한다.
- 현재 그래픽은 기존 인간 그림을 사용한다. 외형 색상과 이름표를 인간과 같게 표시하고 위장 여부/잔여시간 HUD는 본인에게만 표시한다.
- 이는 게임 화면의 외형 위장이다. 기존 공유 상태의 실제 진영·캐릭터 및 위장 상태를 네트워크 수준에서 숨기는 기능은 포함하지 않는다.
- Space가 서버의 기본공격 조건을 만족하면 먼저 위장을 해제하고 즉시 기존 공격 판정을 실행한다. 빗맞혀도 해제 및 2초 공격 쿨타임. 거부된 공격 요청은 위장을 해제하지 않는다.
- Shift 재입력과 시간 만료는 위장 해제 후 500ms 공격 제한. 스킬 쿨타임은 유지하고 자동 공격하지 않는다.
- 기절·활동 불가 상태에서 위장 종료. 경기 종료/초기화에서 위장 상태 정리.
- 재접속 시 서버에서 유지 중인 상태와 타이머를 복원하며 클라이언트는 지속시간을 연장할 수 없다.
