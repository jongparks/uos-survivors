# 개발 상태

- **현재 Phase:** Phase 5 — 캐릭터 시스템 기반 진행 중
- **완료된 Phase:** Phase 0 — 개발 환경 구축, Phase 1 — 싱글플레이 이동 기반, Phase 2 — 멀티플레이 기반, Phase 3 — 네트워크 안정화, Phase 4 — 기본 게임 규칙
- **진행 중인 작업:** 실제 맵과 은신 지형 후보 등록 보류, 후속 인간·좀비 캐릭터 능력 대기, 승리 목표 설계 보류
- **검증된 기능:** pnpm Monorepo, React + Vite 빌드, Phaser 통합, 공개·비공개방, 최대 8명 참여, 서버 권위형 이동·충돌, 입력 시퀀스·비정상 입력 보정, 예측·재조정·보간, 자동·수동 재접속, 인간·좀비 진영, 최초 좀비 배정, 방향·거리 기반 좀비 공격, 즉시 감염, 화석 캐릭터 식별, 서버 권위형 은신·20초 타이머·조기 퇴장·1회 소모, 은신 중 이동·공격 차단, 좀비 공격 대상 제외, 클라이언트별 플레이어 비공개 상태 뷰, 화석 전용 소형 은신처 이펙트 훅, 공개 8인·비공개 2인 통합 테스트
- **알려진 문제:** Phaser가 포함된 초기 번들에 크기 경고가 발생함(기능 영향 없음)
- **다음 작업:** 실제 맵 제작 시 은신처 후보 5개 이상 등록 및 시각 검증, 사용자가 제공하는 다음 캐릭터 능력 추가
- **최근 변경일:** 2026-11-03
