# 개발 상태

- **현재 Phase:** Phase 5 — 캐릭터 시스템 기반 진행 중
- **완료된 Phase:** Phase 0 — 개발 환경 구축, Phase 1 — 싱글플레이 이동 기반, Phase 2 — 멀티플레이 기반, Phase 3 — 네트워크 안정화, Phase 4 — 기본 게임 규칙
- **진행 중인 작업:** 캠퍼스 초안의 아트·세부 배치 다듬기, 추가 맵과 후속 캐릭터 설계 대기
- **검증된 기능:** pnpm Monorepo, React + Vite 빌드, Phaser 통합, 방향키 이동·Shift 능력·Space 상호작용 공용 입력, 공개·비공개방, 최대 8명 참여, 서버 권위형 이동·충돌, 입력 예측·재조정·보간, 자동·수동 재접속, 시대생 및 특수 인간 6종의 인원별 고정 비율·특수 인간 비중복 배정, 최초 좀비 배정, 방향·거리 기반 좀비 공격, 즉시 감염, 화석의 서버 권위형 은신·20초 타이머·정보 비공개, 스과생의 전력 질주·탈진·쿨타임, 조각학도의 최근 5초 이동 기록·85% 속도 조각상·1.5초 좀비 기절·30초 쿨타임, 공대생의 제작·지연 활성 함정·2.5초 ROOT·거리별 전송 가시성·지각생 면역·엑스맨 해제, 감염 시 인간 스킬과 소환물 제거, 공개 8인·비공개 2인 통합 테스트
- **알려진 문제:** Phaser가 포함된 초기 번들에 크기 경고가 발생함(기능 영향 없음)
- **다음 작업:** 제공받는 맵·캐릭터 디자인 반영 및 캠퍼스 실전 플레이 밸런스 확인
- **최근 변경일:** 2026-11-03
- **캠퍼스 아트:** 공식 건물별 사진과 전경을 참고한 부드러운 탑다운 일러스트 적용. 건물별 벽돌·밝은 패널·유리·루버·경사지붕 프로필, 연속 잔디·보도·수목·그림자·하늘못 표현, 맵 선형 보간과 안티앨리어싱 적용. 조경 충돌과 경로 검사 및 실제 브라우저 표시 확인. [사진 근거와 확인 한계](./CAMPUS_ART.md) 참조.
- **캠퍼스/탈출 라운드:** 확장 가능한 공유 맵 등록부, 기본 32px 캠퍼스·48px 개발 맵 선택과 매칭 분리, 야외 건물·연못·외곽 충돌, 스폰 8개·출구 4개·경기별 은신처 5개, 타일 기반 기존 능력 연동. 420초 경기·345초 경고·360초 출구 두 곳 공개·Space 1초 탈출·진영 승리와 개인 결과 구현. 160개 단위 검사, 맵별 경로·도달 시간, 실제 연결 검사 통과. 상세 확장 방법은 [MAPS.md](./MAPS.md) 참조.
- **교수님:** 4타일 최근접 유효 인간 방향키 미션, 서버 무작위 2~4키·오답 초기화·최대 3초 구속·성공 시 조기 해제·본인 기본공격 1초 잠금·40초 쿨타임·정답 개인 전송 구현. 143개 단위 검사 및 배정/연결 검사 통과.
- **시대생/배정:** 방장 확인으로 4~8인 시작, 시작 좀비/참가자/특수 캐릭터 전원 무작위, 인원별 고정 비율 검증, 특수 인간 중복 금지, 본인 캐릭터 소개, 중도 시대생 참여 및 기존 배정 유지 구현. 129개 단위 검사와 실제 4인/8인 배정·중도 참여·감염·재접속 검증 통과.
- **철학도:** 3타일 최근접 좀비 대상·3초 이동 입력 반전·40초 성공 쿨타임·비중첩·진행 중 돌진 방향 유지·엑스맨 위장 유지·혼란 안내/물음표 표시 구현 및 검증.
- **컴과생:** 서버 50ms 위치 표본·3.5초 순환 기록, 정확히 3초 전 위치 보간 복귀, 막힌 과거 경로 탐색, 성공 시 40초 쿨타임, 복귀 직후 위험 감지 재계산 및 순간이동 동기화 검증.
