# 개발 상태

- **현재 Phase:** Phase 5 — 캐릭터 시스템 기반 진행 중
- **완료된 Phase:** Phase 0 — 개발 환경 구축, Phase 1 — 싱글플레이 이동 기반, Phase 2 — 멀티플레이 기반, Phase 3 — 네트워크 안정화, Phase 4 — 기본 게임 규칙
- **진행 중인 작업:** 실제 맵과 은신 지형 후보 등록 보류, 후속 인간·좀비 캐릭터 능력 대기, 승리 목표 설계 보류
- **검증된 기능:** pnpm Monorepo, React + Vite 빌드, Phaser 통합, 방향키 이동·Shift 능력·Space 상호작용 공용 입력, 공개·비공개방, 최대 8명 참여, 서버 권위형 이동·충돌, 입력 예측·재조정·보간, 자동·수동 재접속, 인간 캐릭터 4종 무작위 배정, 최초 좀비 배정, 방향·거리 기반 좀비 공격, 즉시 감염, 화석의 서버 권위형 은신·20초 타이머·정보 비공개, 스과생의 전력 질주·탈진·쿨타임, 조각학도의 최근 5초 이동 기록·85% 속도 조각상·1.5초 좀비 기절·30초 쿨타임, 공대생의 제작·지연 활성 함정·2.5초 ROOT·거리별 전송 가시성·지각생 면역·엑스맨 해제, 감염 시 인간 스킬과 소환물 제거, 공개 8인·비공개 2인 통합 테스트
- **알려진 문제:** Phaser가 포함된 초기 번들에 크기 경고가 발생함(기능 영향 없음)
- **다음 작업:** 실제 맵 제작 시 은신처 후보 5개 이상 등록 및 시각 검증, 사용자가 제공하는 다음 캐릭터 능력 추가
- **최근 변경일:** 2026-11-03
