# 인간 공통 패시브 — 위험 감지 v1.1

- 모든 인간에게 자동 적용, 입력/쿨타임 없음. 조각상은 대상이 아니다.
- 서버는 활동 중인 모든 좀비의 직선거리를 개별 판정하고 최댓값을 적용한다. 벽과 카메라 경계는 검사하지 않는다.
- 4타일 초과 NONE, 2~4타일 WARNING, 2타일 미만 DANGER.
- 위장 엑스맨은 4타일 이내에서 최대 WARNING. 위장 해제 후 일반 거리 규칙 적용.
- 은신 화석은 비활성화. 스과생의 가속/탈진 및 조각상 생성은 영향을 주지 않는다.
- 이동은 100ms마다 검사하고, 감염/위장/은신/접속 상태 변화는 같은 서버 틱에 즉시 재평가한다.
- `danger:update`는 `{ level }`만 해당 인간에게 전송하며 ID/위치/거리/타입을 포함하지 않는다. 상태가 같으면 반복 전송하지 않는다.
- 클라이언트 준비 후 구독하여 초기 단계 수신. 재접속 시 유효 상태 재동기화. 좀비 전환/경기 종료/은신/연결 해제 시 표시 비활성화.
- 화면에 고정된 대칭 붉은 비네트: WARNING 불투명도 0.18, DANGER 최대 0.42와 0.8초 맥동. 전환 0.2초. 방향 표시 없음.
- 비네트는 게임 화면 위의 입력을 가로채지 않는 HTML/CSS 계층이며 카메라 이동/확대와 분리한다.
- 기존 이동/스킬/감염/승리 규칙을 변경하지 않는다. 이전에 제외된 전전컴은 추가하지 않으며, 후속 최종 설계서로 추가된 HUMAN_004 공대생에게도 공통 패시브를 적용한다.
