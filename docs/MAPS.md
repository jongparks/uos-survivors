# 맵과 탈출 라운드

기본 맵은 `MAP_UOS_CAMPUS_V2`이다. 32px 타일, 3120×1680 월드에 건물·하늘못·외곽 충돌, 야외 통로, 8개 스폰, 네 출구, 은신처 후보를 정의했다. 공식 캠퍼스 안내도의 상대 배치를 게임용으로 재구성한 초안이며 실제 측량 도면이나 최종 픽셀 아트가 아니다. 건물 내부는 제공하지 않는다.

참고: https://www.uos.ac.kr/kor/html/auos/guide/map/map.do?identified=anonymous

## 새 맵 추가

1. `packages/shared/src/game/maps/types.ts`의 `GameMapDefinition`을 구현한다. 좌표는 월드 픽셀 단위이며, 바닥 폴리곤·장식·충돌 오브젝트·외곽·스폰·출구·은신처·보호 지점을 분리한다.
2. `registry.ts`의 `GAME_MAPS`에 고유 ID로 등록한다. 대기실 선택 목록과 같은 맵끼리의 빠른 참여에 자동 반영된다. 방 생성 시 서버가 ID와 경로를 검증한다.
3. 서버 이동, 클라이언트 예측, 렌더링은 동일한 맵 데이터를 사용한다. 건물·연못·나무·외곽을 격자 충돌로 변환한다. 장식은 충돌하지 않는다. 필요하면 `collisionTiles`로 직접 격자를 제공할 수 있다.
4. 현재 공통 경기 규칙에 맞춰 스폰 8개 이상, ID가 다른 출구 4개, 야외 은신처 후보 5개 이상을 둔다. `protectedPoints`에 출구와 주요 시설 접근점을 등록하면 책더미가 마지막 접근 경로를 막지 못한다.
5. `pnpm check`를 실행한다. 등록된 모든 맵의 충돌·접근성, 모든 출구 두 곳 조합에 대한 60초 내 도달 경로를 자동 검사한다. 경로 시간은 장애물과 인간 기본 속도 기준이며 좀비 방해나 플레이어 판단 시간을 포함하지 않는다.

`scaleGameMap`으로 전체 크기와 상호작용 반경을 함께 바꿀 수 있다. 캐릭터 몸 크기보다 작은 타일은 허용하지 않는다. 타일 단위 능력은 선택 맵의 타일 크기를 사용한다. 기존 48px 개발용 맵은 회귀 검사와 수동 테스트용으로 유지한다. 방마다 맵 ID를 고정하며 동적 책더미·함정·조각상 등은 공유 정적 맵을 수정하지 않는다.

화석 은신처는 맵 후보 중 경기 시작 시 서버가 정확히 5곳을 선택한다. 사용 가능 표시는 화석에게만 작은 효과로 표시한다. 새 맵의 후보를 등록하면 별도 서버 등록부를 수정할 필요가 없다.

## 라운드 규칙

- 서버 시작 시각부터 420초 경기. 345초에 경고하고 360초부터 탈출 단계이다.
- 서버가 시작 시 출구 4곳 중 2곳을 비공개로 선택한다. 360초 전까지는 모든 출구가 잠겨 있으며 선정 결과를 전송하지 않는다. 열린 출구는 월드 표시·이름·안내 지도로 공개한다.
- 인간이 열린 출구에서 Space를 1초 유지하면 탈출한다. 이동, 입력 해제, 감염, 구속, 연결 끊김 등은 진행을 취소한다. 좀비의 Space 기본공격은 기존대로 작동한다.
- 한 명이라도 탈출하면 인간 승리를 확보한다. 남은 인간의 개인 결과를 위해 계속 진행하며, 활동 중인 인간이 없으면 조기 종료한다. 420초에는 출구를 닫고 탈출하지 못한 인간을 실패로 기록한다.
- 탈출자는 감염·공격·능력 대상에서 제외한다. 감염·탈출·실패 기록은 플레이어가 나가도 방의 라운드 결과에 남는다. 시작 좀비는 인간 개인 결과와 구별한다.
- 인간 배정 비율, 좀비 공격 2초 쿨타임과 기존 캐릭터 능력은 유지한다.

타이머 경계와 탈출 입력 취소는 가상 시각을 사용하는 단위 검사로 검증하며 실제 7분을 기다리는 검사는 아니다. 실제 연결 검사는 캠퍼스/개발 맵 매칭 분리와 4인 시작·비공개방·중도 참여·감염·재접속을 검증한다.
